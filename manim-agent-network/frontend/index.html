The pipeline

Seven agents.
One take.

Each agent is an isolated service with one obsession. They pass the work down the line — and when something breaks, the line heals itself and tries again.

  1. 01

    Script Writer

    Turns your sentence into a structured screenplay — scene by scene, with narration, visual direction, and timing.

    script-writer :8001
  2. 02

    Code Generator

    Writes real Manim Python for every scene in parallel, with API-key pooling to survive rate limits.

    code-generator :8002
  3. 03

    Validator

    Renders each scene in a sandbox, catches every NameError and API drift, and sends bad code back with the stack trace.

    validator :8003
  4. 04

    Voiceover

    Narrates every scene with Kokoro neural TTS — with an espeak fallback so a film never ships silent.

    voiceover :8004
  5. 05

    Image Fetcher

    Pulls supporting visuals when a scene calls for the real world instead of pure mathematics.

    image-fetcher :8006
  6. 06

    Compositor

    Aligns audio to animation, burns native captions, and cuts the scenes into one seamless film.

    compositor :8005
  7. 07

    Orchestrator

    The conductor. A LangGraph state machine that routes work, counts retries, and never loses a job — even through a restart.

    orchestrator :8010

Capabilities

Built to survive
its own mistakes.

Self-healing retries

Failed scenes loop back through generation with the full error log attached. The film ships with whatever survives — never a black frame.

Hybrid rendering

Pure math goes to Manim. Cinematic motion goes to HyperFrames. The script writer decides per scene.

Native captions

Every line of narration is burned into the frame, timed to the voice — no sidecar files.

Key pooling

Multiple NVIDIA NIM keys rotate automatically on 429s, so eight parallel scenes don't starve each other.

Seek-safe encoding

Every render is re-encoded with one-second keyframes — scrub anywhere, the frame is there.

Durable jobs

Job state lives in SQLite, not memory. Kill the orchestrator mid-render; the record survives.
